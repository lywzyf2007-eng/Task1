## 三、第 2 题　定时器（TIM2，更新中断 1ms）

### 3.1 定时器时钟从哪来

- 本工程时钟源为 **HSI = 8 MHz**，`PLL` 关闭，`SYSCLK = 8 MHz`（见 `main.c` 的
  `SystemClock_Config()`）。
- `AHB = /1`，`APB1 = /1`，因此 `PCLK1 = 8 MHz`。
- STM32F1 规则：**APB1 分频为 1 时，定时器时钟 = PCLK1**；只有 APB1 分频不为 1
  时定时器时钟才是 PCLK1 的 2 倍。本工程 APB1 不分频，所以：

```
TIM2CLK = PCLK1 = 8 MHz
```

（以 CubeMX 时钟树显示的 “APB1 Timer clocks = 8 MHz” 为准。）

### 3.2 PSC / ARR 的计算

```
中断周期 = (PSC + 1) × (ARR + 1) / TIM2CLK = 0.001 s
(PSC + 1) × (ARR + 1) = 0.001 × 8 000 000 = 8000
```

取 **PSC = 7999，ARR = 0**：

```
(7999 + 1) × (0 + 1) / 8 MHz = 8000 / 8 000 000 = 0.001 s = 1 ms ✔
```

> ⚠️ 注意：原来的 `PSC=7199, ARR=9` 是按 **72 MHz** 算的（72000/72MHz=1ms），
> 但本工程实际定时器时钟是 8 MHz，那样会得到 9 ms。已改为 8 MHz 下的 1 ms 参数，
> `.ioc` 与 `main.c` 都已同步。

### 3.3 回调代码（写在 `Tasks/src/task.c`）

```c
volatile uint32_t tick = 0;      /* 全局、volatile, 方便 Ozone watch */

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM2)
  {
    tick++;                      /* 每 1ms 自增 1, 约 1000/s */
    HAL_IWDG_Refresh(&hiwdg);    /* 第2题: 喂狗 (由宏控制) */
  }
}
```

- 全局 `tick` 定义在 `task.c`，在 `tasks.h` 中 `extern`。名字必须是 `tick`，
  类型必须是 `volatile uint32_t`。
- 定时器启动在 `Tasks_Init()`：`HAL_TIM_Base_Start_IT(&htim2);`
  中断向量 `TIM2_IRQn` 已由 CubeMX 在 `HAL_TIM_Base_MspInit()` 中使能。
- `tick` 只在中断里改变，没有用 `__HAL_Delay` 或空循环。

## 四、第 3 题　看门狗（IWDG 复位演示）

- IWDG 保持启用，分频、超时都不改：`Prescaler = 64`，`Reload = 1249`。
- `tick` 仍每 1 ms 加 1；**去掉回调里的 `HAL_IWDG_Refresh()`**，重新编译下载。

### 4.1 超时时间

```
超时 = (Reload + 1) × 分频 / LSI
```

F103 的 LSI 手册取 **≈40 kHz**：

```
(1249 + 1) × 64 / 40 000 = 80 000 / 40 000 = 2.0 s
```

（C 板/A 板 LSI ≈32 kHz，同样的分频/Reload 约为 2.5 s；本工程是 F103，取 40 kHz。）

### 4.2 现象

- 因为不再喂狗，IWDG 约 **2 s** 溢出复位一次。
- `tick` 从 0 往上累加（约 1000~2000，取决于实际 LSI），然后随着 MCU 复位回到 0，
  再重新累加，如此反复。
- 超时必须明显大于 1 ms，否则 `tick` 还没来得及加 1 就被复位掉了。

### 4.3 截图

- 附录放 **Ozone 的 `tick` Timeline 或连续监视图**，能看到它先上涨、再归零、再上涨。

## 五、第 2 题 / 第 3 题 切换（重要）

两题的代码只差“回调里要不要喂狗”，在 `Tasks/src/task.c` 顶部用宏切换：

```c
#define IWDG_REFRESH_IN_TIM_CALLBACK   0
```

- `1` = 第 2 题：喂狗，`tick` 持续增长（截第 2 题的图时改成 1，重新编译下载）。
- `0` = 第 3 题：不喂狗，约 2 s 复位（交作业默认值，截第 3 题的图）。
